A

Let AI in

access · 01–04

01

Let the AI bots in

Many sites still block the exact bots that would cite them. Allow all three.

# robots.txt User-agent: OAI-SearchBot Allow: / User-agent: PerplexityBot Allow: / User-agent: Claude-SearchBot Allow: /
02

Get indexed by Bing

ChatGPT search finds pages through Bing. Resubmit on every update.

# on every publish Bing Webmaster Tools → submit IndexNow → ping
03

Ship a markdown twin

A clean .md copy of the page, written for AI agents. No scripts, menus or popups. Listed in llms.txt.

# llms.txt /pricing → /pricing.md /vs-rival → /vs-rival.md /docs/setup → /docs/setup.md
04

Make sign-up agent-proof

AI agents now sign up for tools for their users. Many die at the login wall.

# run an agent through it agent → lands on page ✓ agent → fills sign-up ✓ agent → login wall ✕ breaks here
B

Give it something to quote

content · 05–08

05

A first paragraph AI can lift

Definition first, a number second, both inside the first 50 words. That's what ChatGPT quotes word for word.

# first 50 words words 01–25 → what it is words 26–50 → one hard number everything else → after
06

A stat only you have

The first page to publish “43% of X” gets cited. The 100 pages repeating it don't.

# who gets the citation original stat → cited ✓ 100 copies of it → ignored
07

Comparison tables in HTML

AI can't read a table inside an image. In HTML, every row can show up in “X vs Y” answers.

# same table, two formats <table> → every row readable ✓ table.png → invisible to AI
08

An FAQ built from buyer prompts

Ask ChatGPT what your buyers ask it. Answer each question in 2–3 sentences.

# per question Q → a real buyer prompt A → 2–3 sentences, no fluff
C

Prove you're real

trust · 09–10

09

A named author, matching schema

A LinkedIn profile and dates that match the schema. Pages with no author look like content farms.

# schema, matching the page "author": "Jane Doe", "sameAs": "linkedin.com/in/…", "dateModified": "= page date"
10

Inline sources, real expert quotes

Link sources in the text. Quote people with real names. Citations, quotes and stats all lift AI visibility.

+40%up to, in AI answersfrom citations, quotes and stats
